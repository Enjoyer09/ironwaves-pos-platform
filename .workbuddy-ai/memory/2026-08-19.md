## Railway Deploy Fix — Migration Crash
- Railway deploy failed healthcheck: `/health/deep` never responded (503 → "1/1 replicas never became healthy")
- Root cause: `backend/alembic/versions/20260819_0001_add_tenant_branches.py` used SQLite-only `randomblob()`/`hex()` functions in the backfill INSERT — these don't exist in PostgreSQL (Railway uses PG)
- The migration crashed during `alembic upgrade head` in the Docker CMD, so uvicorn never started, so the healthcheck endpoint never came up
- Fix: Added dialect check (`conn.dialect.name == "postgresql"`) — PG path uses `gen_random_uuid()` + `NOW()` + `CREATE EXTENSION IF NOT EXISTS pgcrypto`; SQLite path keeps `randomblob()` + `datetime('now')`
- Committed and pushed fix (commit 846028a2) — Railway will auto-rebuild

# Contributing to IronWaves POS Platform

Thank you for your interest in contributing to **IronWaves POS Platform** — a high-performance, multi-tenant cloud point-of-sale, inventory, and restaurant/retail operations platform.

## Our Philosophy
IronWaves is built to solve real-world checkout latency, hardware integration, and multi-tenant isolation challenges in active retail and dining environments.

## How to Contribute

### 1. Issues & Feature Requests
- Check open issues before creating a new one.
- Provide concrete reproducible steps or architectural context for enhancements.

### 2. Pull Requests (PRs)
1. Fork the repo and create your branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. Ensure consistent code style, linting, and automated test passes.
3. Commit with concise, descriptive messages.
4. Submit your PR with a description of what changed and how it was tested.

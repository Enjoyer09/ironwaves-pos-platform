01 / Niyə məhz bu istiqamətŞüşədən sonra nə gəlir

Keçən konsept Apple Liquid Glass idi. Araşdırma göstərdi ki, 2026-da şüşə geriyə çəkilib: yalnız naviqasiya zolağı və kontrollar üçün işlədilir, məzmun isə möhkəm səthdə qalır. Yəni şüşə artıq "dizayn" deyil — kiçik bir alətdir. Dizaynın ağırlığı başqa yerə keçib: tipografiyaya, şəbəkəyə və material hissinə.

    03 / MaterialRəng və səth token-ları

    Kontrast qeydləri

    Keçən cütlər
    • #1a1611 kağız #f5f1e8 üzərində → ~16:1
    • #5a5147 kağız üzərində → ~6.9:1
    • #b4471f kağız üzərində → ~4.8:1 (AA keçir; yalnız 14px+ üçün)
    • Ağ mətn #b4471f möhür dairəsi üzərində → ~5.4:1
    Qadağa
    • Terracotta rəngini kiçik mətn üçün işlətmə — yalnız nişan, xətt, möhür, və 14px+ başlıq.
    • Qızılı (--p-metal) yalnız "mükafat hazır" halında — adi element üçün işlətsən, dəyəri itir.
    • Kağız tonunu iki səviyyədən çox qatlama — sənəd palçıqlı görünür.

    04 / TipŞkala və ritm

    Bu sistemin ən böyük fərqi: rəqəm və başlıq serif-dir. "12.50 ₼" və "6/10" sadəcə məlumat deyil — kompozisiyanın ən böyük elementidir. Yüzdə 50 siyahı, yüzdə 50 plakat.

    Şrift seçimi — praktik qərar

    Serif kimi sistemi mövcud şriftlərdən götürürük: Iowan Old Style → Palatino → Georgia. iOS-da birinci işləyir, Android-də Georgia-ya düşür. Heç bir şrift faylı yüklənmir — tətbiq yüngül qalır. Daha kəskin fərq istəyirsənsə, sonradan bir dəyişən (variable) serif əlavə edilə bilər (məs. Fraunces, Instrument Serif) — amma konsept onsuz da tam işləyir.

    05 / QaydalarEt / Etmə

    Et
    • Hər ekranda bir dominant tip element — qalanı ona xidmət edir.
    • Dərinliyi haşiyə + boşluq ilə qur. Kölgə yalnız "kağız üstə kağız" üçün, maks. 24px yayılma.
    • Rəqəmi böyüt — balans, möhür, qiymət. İstifadəçi məlumatı oxumadan görsün.
    • Hairline (1px) xətləri səthi bölmək üçün işlət — kart-kart ayrılığı üçün deyil, içəri struktur üçün.
    • Möhür/perforasiya kimi fiziki detalları CSS ilə çək, şəkil faylı yükləmə.
    • Reduce Motion açıqsa kinetik lent də, möhür animasiyası da dayansın.
    Etmə
    • Blur, glass, parıltı, qradient qat əlavə etmə — bu sistem onların əksi kimi qurulub.
    • Serif başlığı 3 sətirdən çox uzatma; ekranı "şeir"ə çevirmə.
    • Radius-u hər yerdə böyütmə. Kart 3px, düymə tam dairə — bu qəsdən asimmetriyadır, onu "düzəltmə".
    • Terracotta-nı fon kimi işlətmə — o, möhürdür, divar deyil.
    • İkonları dolu/rəngli etmə — stroke 1.6, tək rəng, 18–26px.

    Hərəkət dili

    Möhür basma (180ms)

    İstifadəçi "Möhür bas" düyməsinə toxunanda boş dairə scale(1.35) → 1 kiçilir, rəngi mürəkkəbə çevrilir, bir anlıq rotate(-12deg) əyilir. Fiziki möhürün ekrandaki qarşılığı — sistemi "oyun" deyil, "sənətkarlıq" hiss etdirir.

    Kinetik lent (26s loop)

    Əsas ekrandaki incə hərəkətli zolaq — günün yeni məhsulu və kampaniyası. Statik banner-dən güclüdür, çünki göz onu izləyir və iki dəfə oxuyur. prefers-reduced-motion → tam dayanır.

    06 / KeçidNecə tətbiqə salırıq

    Eyni qayda: yeni kod heç bir yerə import olunmur, POS/admin toxunulmur. Müştəri tətbiqi tədricən bu sistemə keçir, hər addımda sən telefonda yoxlayırsan.

    1. Token qatı

      src/theme/craft-tokens.css — yuxarıdaki dəyişənlər, .customer-craft + data-craft-theme scope-u ilə. Quiet UI v2 ilə yan-yana yaşayır, heç nəni əvəz etmir.

    2. Alt naviqasiya + status zolağı

      Kağız zolaq, hairline ayırıcı, üstdə 3px mürəkkəb indikator. İlk real fərq burada görünür.

    3. Əsas ekran

      Cover başlıq + dateline + kinetik lent + möhür kartı (real möhür sayı ilə) + bento tiles + sifariş zolağı.

    4. Menyu

      Tip-first siyahı: serif ad + serif qiymət + hairline. Mövcud axtarış və kateqoriya məntiqi olduğu kimi qalır.

    5. Kart / balans / mükafat

      Qəbz metaforu, real balans və möhür məlumatı, "Artır" düyməsi epoint hazır olanda işə düşür.

    6. Təmizlik

      Köhnə dekorativ kölgələr və qradiyent qalıqları silinir. Hər addımdan sonra: typecheck → smoke → parity → build → telefon quraşdırma → sən yoxlayırsan.

    Risk və geri dönüş
    • Hər addım ayrı commit → bəyənməsən geri qaytarmaq asandır.
    • Backend, ödəniş, loyallıq məntiqi heç toxunulmur — yalnız görünüş.
    • Dark Roast rejimi ayrı token dəsti olduğu üçün sıfırdan sınanır.
    Növbəti qərar sənin
    • Bu istiqaməti seçsən → 1-ci addımdan başlayıram və hər addımı telefonda yoxlayırsan.
    • Liquid Glass ilə bunu qarışdırmaq olmaz — ikisi fərqli material dilidir, biri seçilməlidir.
    • Üçüncü variantı da istəyirsənsə (məs. tam type-first, kartsız, təmiz plakat) — de, ayrı konsept qururam.

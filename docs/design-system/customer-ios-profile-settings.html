Profil ekranı sazlama olmadan profil deyil

Haqqın var — mövcud profil ekranında heç bir sazlama yoxdur. Kodu oxudum: çıxış, Apple Wallet, sevimli filial, hüquqi səhifələr, dəstək əlaqəsi, versiya — heç biri ProfileTab.tsx-də yoxdur. Ən pisi: funksiyaların çoxu app-də artıq var, sadəcə profilə bağlanmayıb. Aşağıda tam taksonomiya və işlək ekranlar.

01 / Kod auditiNə var, nə yox

Bunu təxmin etmədim — faylları oxudum. Hər sətirdə ya "koddadır", ya "yoxdur" yazılıb. Maraqlısı: demək olar hamısı artıq koddadır, yalnız interfeysə bağlanmayıb.

SazlamaMövcud profil ekranıKoddaki vəziyyət
Çıxış (logout)YOXDURMexanizm hazırdır: clearCustomerSession() + setSessionCreds({cardId:'',token:''}) — silmə axınında artıq işlədilir
Apple Wallet kartıYOXDURshowWallet bayrağı + get_customer_wallet_pass_url() hazırdır — yalnız ana ekranda istifadə olunur
Sevimli filialYOXDURstores siyahısı + selectedStoreId + selectedStore hazırdır — filial seçimi yalnız sifariş ekranındadır
Bildiriş seçimləriYalnız oxuma siyahısıPush token qeydiyyatı var (save_push_token) — seçim (toggle) yoxdur
Məxfilik / ŞərtlərYOXDURYoxdur — App Store tələbidir, URL host etmək lazımdır
Dəstək əlaqəsiYOXDURPayload-da var: branding.phone, branding.address, branding.company_name
Versiya nömrəsiYOXDURYoxdur — build nömrəsi (.plist) oxunmalıdır
Nə üçün bu vacibdir
  • Çıxış olmayan app hesab app deyil. İstifadəçi hesabını dəyişə bilmir, paylaşılan telefonda qalır.
  • Hüquqi səhifələr App Store-un rədd səbəbidir. Məxfilik siyasəti linki olmayan loyallıq app-i təsdiqdən keçmir.
  • Dəstək əlaqəsi olmayan app-də istifadəçi ilişir. Problem olanda nə edəcəyini bilmir.
Ən böyük itki: çıxış

F5-də hesab silmə əlavə etdik (Apple 5.1.1 üçün). Amma çıxış yoxdur. Bu, məntiqsiz vəziyyətdir: istifadəçi hesabı tamamilə silə bilir, amma sadəcə çıxa bilmir. Üstəlik clearCustomerSession() funksiyası onsuz da hazırdır — yəni bu, 10 sətirlik işdir.

02 / TaksonomiyaYeddi qrup

Apple-ın öz Settings naxışını izlədim: qruplar məntiqi sıra ilə — əvvəl şəxsi, sonra tətbiq, sonra təhlükəli. Təhlükəli əməliyyatlar həmişə ən sonda və ayrı qrupda.

1Hesab
  • Ad və doğum tarixi — redaktə mövcud
  • Telefon nömrəsi — dəyişmək OTP ilə
  • Üzvlük kartı № — oxunaqlı, uzun
  • Kart növü / səviyyə — nişan kimi
2Tətbiq görünüşü
  • Görünüş: İşıqlı / Qaranlıq / Avtomatik mövcud
  • Dil: AZ / EN / RU mövcud
  • Avtomatik seçim yeni: sistemə uyğunlaş
3Bildirişlər
  • Sifariş hazırdır — ən vacib, default açıq
  • Təkliflər və kampaniyalar
  • Möhür xatırladıcı — "1 möhür qaldı"
  • Yeni məhsullar
  • Hamısı susdur yeni
4Kart & ödəniş
  • Sevimli filial məlumat var UI yeni
  • Apple Wallet kartı — Əlavə et mövcud UI yeni
  • Balans avtomatik artırma — toggle
  • Ödəniş üsulu — kassa / kart / balans
5Dəstək
  • Bizimlə əlaqə — telefon + ünvan payload-da var
  • Tez-tez verilən suallar
  • Rəy göndər — mövcud feedback axını
  • Problem bildir — sifariş nömrəsi ilə
6Hüquqi
  • Məxfilik siyasəti URL host etmək lazım
  • İstifadə şərtləri URL host etmək lazım
  • Açıq mənbə lisenziyaları
  • Versiya — build nömrəsi ilə
7Təhlükəli zona
  • Çıxış — adi əməliyyat, konfirmasiya ilə mexanizm hazır
  • Hesabı sil — birdəfəlik, Apple 5.1.1 mövcud
  • İkisi ayrı qrupda və ən sonda
Nə üçün çıxış və silmə ayrı səviyyədədir

İkisi də "hesabdan çıxma"dır, amma nəticəsi tam fərqlidir: çıxış geri qaytarıla bilər (yenidən daxil olursan, möhürlər qalır), silmə geri qaytarılmır. Ona görə çıxış adi sətirdir, silmə isə qırmızı və tək təsdiqlə. İkisini birlikdə qoysan istifadəçi səhvən silməyə basar.

Çıxış bir toxunuşdur çünki geri qaytarıla bilər. Silmə iki mərhələlidir çünki qaytarılmır. İkinci ekranda "əvvəlcə balansı istifadə et" xəbərdarlığı var — istifadəçi 12.50 ₼-ni itirməsin. Apple-ın özü də bu naxışı işlədir.

Bildiriş açarları real işləyir

Push token artıq qeydiyyatdan keçir. Açar bağlananda biz tokeni silmirik, yalnız müvafiq kategoriyanın göndərişini dayandırırıq — istifadəçi sonra açsa, yenidən icazə istəmək lazım gəlmir (iOS yalnız bir dəfə soruşur).

05 / Keçidİcra planı

Bu, v3-dən daha sadə işdir: yeni data yoxdur, mövcud funksiyalar interfeysə bağlanır. Sıra belədir — 1-ci addım onsuz da 10 sətirdir.

  1. Çıxış + versiya + hüquqi sətirlər

    Ən az iş, ən çox təsir. clearCustomerSession() çağırışı + təsdiq sheet-i. Versiya package.json-dan. Hüquqi URL-lər sonra doldurulacaq. Bununla App Store blokeri də bağlanır.

  2. Profil kartı + statistika

    Avatar, ad, telefon, üzvlük nömrəsi, səviyyə nişanı + 3 statistika (möhür/balans/kupon). Hamısı mövcud payload-dan.

  3. Bildiriş açarları

    4 açar. Yerli yaddaşda saxlanır, push göndərişində filtr kimi işlənir. Backend dəyişmir.

  4. Filial seçimi

    stores + selectedStoreId hazırdır — profilə bağlanır ki, sifariş ekranından asılı olmasın.

  5. Apple Wallet sətri

    showWallet bayrağı yoxlanır: sertifikat yoxsa sətir "Konfiq. olunmayıb" göstərir və söndürülür (F5-dəki davranışla eyni).

  6. Dəstək + FAQ

    Əlaqə branding.phone/branding.address-dən. FAQ mətn siyahısı — statik.

Nə qazanırıq
  • İstifadəçi hesabını dəyişə bilir — bu, buraxılış blokeridir.
  • App Store üçün hüquqi səhifələr hazır olur (URL host ediləndən sonra).
  • Apple Wallet kartı görünür — hazır funksiya nəhayət istifadə olunur.
  • Bildiriş seçimi → istifadəçi app-i silmir, sadəcə susdurur.
Açıq qalan 2 iş (səndən)
  • Məxfilik siyasəti URL-i — mətn hazırlaya bilərəm, host etmək lazımdır. App Store göndərişi üçün mütləqdir.
  • İstifadə şərtləri — eyni.
  • İkisi hazır olana qədər sətirlər görünür, amma "hazırlanır" vəziyyətində qalır.
